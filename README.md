# MNIST 手写数字分类（ANN vs CNN 对比实验）

用 PyTorch 从零实现手写数字识别，核心是一次**对照实验**：同样的数据、同样的训练流程，只换模型结构（全连接 ANN vs 卷积 CNN），用准确率差异来理解「为什么图像任务用 CNN」。

## 实验结果

在测试集 10000 张图上（5 个 epoch，RTX 4060 Laptop GPU 实测）：

| 模型                 | 参数量     | 测试准确率      | 5 轮总耗时 |
| ------------------ | ------- | ---------- | ------ |
| ANN（3 层全连接）        | 235,146 | **97.73%** | ~45s   |
| CNN（2 卷积层 + 2 全连接） | 421,642 | **99.20%** | ~59s   |

CNN 只比 ANN 高约 1.5 个百分点，但**错误率从 2.27% 降到 0.80%，接近降到三分之一**——这个差距在高置信场景（如票据识别）里是质变。

## 为什么 CNN 更适合图像

**ANN 的问题**：把 28×28 的图拉平成 784 维向量后，「左上角像素」和「它右边的像素」在网络眼里只是两个独立的数字，空间结构被完全丢掉了。

**CNN 的做法**：保留二维结构，用卷积核在图上滑动，逐层提取「边缘 → 笔画 → 局部形状」这类空间特征。这就是两者准确率差异的来源。

## 目录结构

```
├── src/
│   ├── model.py         # ANN 和 CNN 的模型定义（带逐层注释）
│   ├── data_loader.py   # 数据下载、预处理、分批加载
│   ├── train.py         # 训练与评估，支持 --compare 做对照实验
│   └── predict.py       # 推理：随机样本演示 + 预测自己的手写图片
├── figures/             # 训练曲线、对比图、预测示例（运行后生成）
├── test_images/         # 手写测试图（黑底白字 / 白底黑字两种风格）
├── drawing-board.html   # 鼠标手写画板：写数字 → 保存 PNG → 喂给模型
├── data/                # MNIST 数据集（首次运行自动下载，已被 .gitignore 排除）
├── requirements.txt
└── README.md
```

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 训练并对比 ANN / CNN（生成对比图和 benchmark_result.json）
python src/train.py --compare --epochs 5

# 3. 只训练某一个模型
python src/train.py --model cnn --epochs 5

# 4. 用训练好的模型预测自己的手写图片（白底黑字拍照即可）
python src/predict.py --model cnn --image 你的图片.png

# 5. 或者随机抽测试集样本看预测效果
python src/predict.py --model cnn --demo
```

## 手写数字测试

项目自带三种测试方式，从易到难：

**方式一：用现成测试图（零门槛）**

`test_images/` 里已经放了 6 张测试图（数字 3、5、7 各两种风格）：

```bash
# 黑底白字（MNIST 原生风格）
python src/predict.py --model cnn --image test_images/mnist_style_7.png

# 白底黑字（模拟黑笔写白纸的照片，会走自动反色逻辑）
python src/predict.py --model cnn --image test_images/photo_style_3.png
```

**方式二：鼠标画板（推荐体验）**

打开项目根目录的 `drawing-board.html`，用鼠标在黑板上写一个数字 → 点「保存 PNG」→ 把下载的图放进 `test_images/` → 用方式一的命令预测。鼠标写的笔画比纸笔更粗，是观察模型能力边界的有趣样本。

**方式三：真实手写拍照（最有挑战）**

用黑笔在白纸上写一个数字，拍照传进电脑。光线、笔画粗细、倾斜度都和 MNIST 不同——模型可能翻车，而「分析它为什么翻车」正是从跑通教程走向理解模型的分界线（数据增强、域偏移都是由此引出的经典话题）。

`predict.py` 内置了把「真实照片」转成「MNIST 风格输入」的完整预处理：灰度化 → 自动反色 → 内容裁剪 → 等比缩放 20×20 → 居中贴到 28×28 画布。

## 学到什么

- **训练闭环**：前向传播 → 损失计算 → 梯度清零 → 反向传播 → 参数更新，所有深度学习训练都是这五步
- **ANN vs CNN 的本质区别**：拉平丢空间信息 vs 卷积保留空间信息
- **标准化的重要性**：训练和推理必须用同一套预处理（`data_loader.py` 共享给两边就是这个目的）
- **实验习惯**：固定数据与流程、只改一个变量、把结果量化成表格
